# Sorties du générateur Leif

Dossier rempli par `node scripts/leif/generate-images.mjs <set>` (voir [`../PROMPTS.md`](../PROMPTS.md)) : un sous-dossier par set (`directions/`, `reference/`, `expressions/`, `fullbody/`, `card/`), chacun avec ses PNG et un `manifest.json` (prompt exact, modèle, références, date).

On peut committer les images **retenues** (légères, utiles comme référence). Les fichiers lourds — explorations complètes, upscales pour l'impression, modèles 3D, vidéos — vont sur le **Google Drive Drakkar**, pas dans le dépôt.
